# Григорьев & Малыгин — демоверсия сайта

[Открыть сайт](https://ilyasemenovya.github.io/grigoryev-malygin-bar/)

Первый вариант сайта выездного бара в Чебоксарах для обсуждения с командой. Название рабочее.

Четыре формата бара, фотографии основателей, порядок заказа и контакты. Звонок и SMS открывают соответствующие приложения; данные посетителей сайт не сохраняет.

Портреты предоставлены командой. Коктейльные изображения сгенерированы для макета.

## Исходники и сборка

`source.zip` содержит исходники. Для сборки требуются Node.js 22.13+ и pnpm:

```sh
pnpm install --frozen-lockfile
pnpm build
```

Готовый файл `demo/index.html` включает фотографии, шрифты, стили и скрипты. Его можно открыть напрямую в браузере. Для обновления GitHub Pages замените `index.html` в корне репозитория.

Сборка использует те же React-компоненты, что и исходный макет. В `demo-src/site.css` сохранены подготовленные стили и шрифты. GitHub Pages: ветка `main`, каталог `/`.
