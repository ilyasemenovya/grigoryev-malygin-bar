# Григорьев & Малыгин — демоверсия сайта

[Открыть сайт](https://ilyasemenovya.github.io/grigoryev-malygin-bar/)

Первый вариант сайта выездного бара в Чебоксарах для обсуждения с командой. Название рабочее.

Видео на первом экране, светлая серия коктейльных кадров, четыре формата бара, фотографии партнёров, порядок заказа и контакты. Звонок и SMS открывают соответствующие приложения; данные посетителей сайт не сохраняет.

На компьютере текст и видео первого экрана расположены в отдельных колонках, на телефоне — друг под другом. У разделов общая сетка и внешние отступы; вопросы и ответы находятся в колонке с этапами заказа. Фотографии коктейлей показаны без технических названий бокалов.

Портреты предоставлены командой; фон и свет приведены к общему стилю с помощью ImageGen. Коктейльные изображения сгенерированы для макета и не являются портфолио мероприятий или утверждённым меню.

Видео первого экрана — монтаж из [присланного пользователем референса Decadent Depictions](https://ru.pinterest.com/pin/1090434128546075955/), «It hits different this way.». Это демонстрационный материал, а не съёмка команды. Сохранены только крупные планы рук, напитков и посуды, без лица бармена. Продолжительность — 7,1 секунды. Звуковая дорожка удалена; для повтора добавлен короткий переход через тёмный кадр. По просьбе владельца автозапуск включён на всех размерах экрана, включая режимы уменьшения движения и экономии трафика. Если браузер запрещает видеоплееру запуск или видео недоступно, автоматически показывается анимированная WebP-копия того же монтажа. Она загружается только при таком отказе. Оба варианта можно приостановить; вне первого экрана и в скрытой вкладке движение останавливается. При ошибке обоих вариантов доступны повторный запуск и ссылка на видео.

## Исходники и сборка

`source.zip` содержит исходники. Для сборки требуются Node.js 22.13+ и pnpm:

```sh
pnpm install --frozen-lockfile
pnpm build
```

Готовый файл `demo/index.html` включает фотографии, шрифты, стили и скрипты. Рядом находятся `demo/hero-bar-v1.mp4` и резервная анимация `demo/hero-bar-motion-v1.webp`. Для локального просмотра сохраните три файла рядом и откройте `index.html`. Для обновления GitHub Pages замените их в корне репозитория.

Сборка использует те же React-компоненты, что и исходный макет. Стили в `styles/bar.css` используются и в локальном макете, и при сборке. В `demo-src/fonts.css` сохранены встроенные шрифты. Фотографии появляются при прокрутке; настройки уменьшения движения учитываются. GitHub Pages: ветка `main`, каталог `/`.
