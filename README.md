# Григорьев & Малыгин — демоверсия сайта

[Открыть сайт](https://ilyasemenovya.github.io/grigoryev-malygin-bar/)

Первый вариант сайта выездного бара в Чебоксарах для обсуждения с командой. Название рабочее.

Видео на первом экране, светлая серия коктейльных кадров, четыре формата бара, фотографии партнёров, порядок заказа и контакты. Звонок и SMS открывают соответствующие приложения; данные посетителей сайт не сохраняет.

Портреты предоставлены командой; фон и свет приведены к общему стилю с помощью ImageGen. Коктейльные изображения сгенерированы для макета и не являются портфолио мероприятий или утверждённым меню.

Видео первого экрана — [присланный пользователем референс Decadent Depictions](https://ru.pinterest.com/pin/1090434128546075955/), «It hits different this way.». Это демонстрационный материал, а не съёмка команды. Звуковая дорожка удалена; для повтора добавлен короткий переход через тёмный кадр. Видео можно приостановить. При уменьшении движения или экономии трафика показывается статичный кадр; воспроизведение приостанавливается вне первого экрана и в скрытой вкладке.

## Исходники и сборка

`source.zip` содержит исходники. Для сборки требуются Node.js 22.13+ и pnpm:

```sh
pnpm install --frozen-lockfile
pnpm build
```

Готовый файл `demo/index.html` включает фотографии, шрифты, стили и скрипты. Рядом находится отдельный `demo/hero-bar-v1.mp4`, который загружается только для фонового воспроизведения. Для локального просмотра сохраните оба файла рядом и откройте `index.html`. Для обновления GitHub Pages замените `index.html` и `hero-bar-v1.mp4` в корне репозитория.

Сборка использует те же React-компоненты, что и исходный макет. Стили в `styles/bar.css` используются и в локальном макете, и при сборке. В `demo-src/fonts.css` сохранены встроенные шрифты. Фотографии появляются при прокрутке; настройки уменьшения движения учитываются. GitHub Pages: ветка `main`, каталог `/`.
